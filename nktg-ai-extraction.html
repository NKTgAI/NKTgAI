How to use the Extraction feature

Extraction is NKTg AI's core feature, helping you distill the most important content from a text based on its semantic structure. Instead of generating new content, Extraction preserves the original information and removes parts that are redundant, repetitive, or low in semantic value.

What is Extraction?

Extraction uses NKTg AI's algorithm to analyze the semantic structure and determine:

  • The AMP / DAMP / STABLE structure
  • The Core Sentence
  • The Compression level
  • The content with the highest semantic value

The result is a more concise version that still preserves the document's core information.

Supported file formats

You can enter data in two ways:

  • Paste text directly into the input box
  • Upload a file from your computer using the + button

NKTg AI supports the following formats: TXT, DOCX, PDF, PNG, JPG, WEBP. For images or scanned documents, the system uses OCR to recognize the text before analysis.

How to use Extraction

Step 1. Select Extraction

On the main screen, click Extraction to switch to text-distillation mode.

Step 2. Enter your content

You can paste text directly or upload a document from your computer. Then click Submit to start the analysis.

Step 3. Wait for NKTg AI to analyze

The results shown include:

  • The AMP / DAMP chart
  • The Core Sentence
  • The compression ratio
  • The distilled text

Understanding the analysis results

The AMP / DAMP chart

AMP indicates content focused on action and outcomes. DAMP indicates content leaning toward analysis, evaluation, or risk. STABLE indicates balanced or neutrally descriptive content.

Core Sentence

The sentence with the highest Semantic Energy, clearly expressing the core content. It is determined by the algorithm, independent of its position in the text.

Compression ratio

Shows the number of tokens and characters before and after distillation, along with the compression ratio.

Choosing an Extraction level

  • Standard: Retains the most information, removing redundant/repetitive content.
  • Condensed: Removes less important examples and explanations, more concise.
  • Essence: Keeps only the sentence with the highest semantic value, for the fastest grasp of the core content.

Copying the result

Once finished, you can click Copy to copy the entire result and use it in reports, research, notes, or other documents.

Tips for the best results

  • Use clear text in the correct format
  • Scanned images or documents should be good quality for accurate OCR
  • Well-structured documents usually give better results
  • For very short texts, the difference between Extraction levels may be negligible

Notes

  • Extraction only distills content from the original text — it does not generate new information
  • Results are drawn directly from the document you provide
  • Processing happens directly in the browser via WebAssembly — no upload to a server, no cloud service, no remote storage
  • Even without an Internet connection, NKTg AI can still process the document on your device
