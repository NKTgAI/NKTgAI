Changing the Interface Language in NKTg AI

NKTg AI supports multiple interface languages, making the app more convenient for users around the world. You can change the language at any time in Settings → Language.

Changing the language only affects the user interface, such as menus, buttons, and notifications. NKTg AI's text analysis capability does not change.

Supported languages

  • English
  • Tiếng Việt
  • Français
  • Deutsch
  • Español
  • 中文
  • 日本語
  • Русский

How do I change the language?

  1. Go to https://nktg.org/
  2. Log in to your NKTg AI account
  3. Open Settings
  4. Select Language
  5. Click the language you want to use

Once selected, the interface will switch to the new language.

What does changing the language affect?

Changing the language applies to these interface elements:

  • Function menus
  • Buttons
  • Dialogs
  • System notifications
  • Guide pages and other interface content

What doesn't change?

  • NKTg AI's text extraction capability
  • The analysis algorithm
  • Extraction or Addition results
  • Your daily usage count
  • Your subscription plan

How many times can I change the language?

You can switch between languages at any time. There is no limit on the number of changes.

Which language should I choose?

Choose the language you're most comfortable with for a more convenient interface experience. Your language choice does not affect the quality of NKTg AI's text analysis.

Troubleshooting

If you've selected a new language but the interface hasn't changed:

  • Make sure you selected the correct language under Language
  • Refresh the page if needed
  • If the issue persists, please contact support

Need more help?

If you run into trouble changing the language, or notice a translation error in the interface, please contact NKTg AI support.
